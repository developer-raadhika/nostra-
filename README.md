 # 🛍️ Nostra – Fashion E-Commerce Website

Nostra is a simple and responsive fashion e-commerce website created using **HTML, CSS, and JavaScript**. It features a clean design, product sections, search functionality, interactive elements, animations, and responsive layouts.

### 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Responsive Design

### ✨ Features

* Responsive navigation bar
* Product collection
* Search functionality
* Interactive elements
* Simple animations
* Mobile-friendly design
